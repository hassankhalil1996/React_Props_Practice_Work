# My Contacts App

This is a simple React app that displays contact information using reusable components. The app uses a `Card` component to display contact details like name, phone number, and email for each contact.

## Features

- Displays contact cards with user information.
- Reusable `Card` component that receives contact data as props.
- Designed using basic CSS to style the contact cards.
- Includes a sample contact data file (`contacts.js`) to manage the contact information.
